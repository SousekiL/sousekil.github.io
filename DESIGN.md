## Voice & Tone

- **Adjectives:** precise, evidence-first, decision-oriented, academic, understated
- **Tone:** Calm academic-professional: lead with the research question, method, and outcome. Prefer measured claims, research framing, and role-ready signals over hype.

### Messaging pillars
- Decision-oriented analytics, not vanity metrics
- Causal inference, risk modeling, and extreme value methods
- Selected work with clear questions, methods, and outcomes
- Open to Data Scientist, Actuarial Analyst, and Risk Analytics roles

### Vocabulary
- **Use:** causal inference, risk modeling, extreme value theory, computational social science, evidence snapshot, selected work, methods, outcomes, quick signals
- **Avoid:** 10x, disrupt, synergy, rockstar, ninja, guaranteed, world-class

## Imagery

- **Style:** Research figures, network graphs, time-series charts, project-slide hero images, and restrained academic portfolio photography
- **Subjects:** personal avatar / bio photo, social network visualizations, extreme precipitation / return-level charts, project title slides and talk screenshots, template homepage mockups, statistical output and methodology diagrams
- **Treatment:** Clean white or charcoal canvas; charts with muted axes; teal accents used sparingly for links and highlights; photography desaturated or natural; project thumbnails 6px radius with soft shadow, summary cards 16px radius with a light surface border
- **Avoid:** neon gradients, stock handshake photos, emoji icon grids, aggressive purple washes, fake 3D product renders

## Layout

- **Radius:** 4px
- **Border weight:** 1px
- **Spacing:** 8px baseline with 1.5 body line-height; masthead 70px; content max-width centered; section gaps ~3rem; grid gaps 1rem

### Posture rules
- Light academic canvas (#fff) with charcoal dark theme (#474747) toggle
- Serif body (Times New Roman) + system sans display for headings and UI chrome
- Single teal accent for links and primary actions; gray base for default buttons (#7a8288)
- Base radius 4px on buttons and code chips; summary/project cards use 16px radius with a soft 12px/32px shadow
- Cards use a 1px surface-colored border (#f2f3f3) on white background
- Sidebar + masthead shell (Minimal Mistakes / Academic Pages): 1024px sidebar breakpoint
- Homepage hero title uses fluid clamp(2.4rem, 5vw, 4.4rem) with tight 1.02 line-height
- Section grids use CSS auto-fit (minmax 180px–250px) for snapshots and project cards
- Project cards follow a Question / Method / Result pattern with compact action rows
